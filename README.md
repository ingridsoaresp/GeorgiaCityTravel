# 🗺️ Georgia City Travel

A JavaScript web application that generates driving directions between cities in Georgia using the Google Maps Directions API.

## Overview

This project allows users to select a starting city and a destination city from predefined locations in Georgia. The application then displays the driving route on an interactive map along with turn-by-turn directions.

The project was developed to practice JavaScript, DOM manipulation, event handling, and integration with external APIs.

---

## Features

- Interactive Google Maps integration
- Driving route visualization
- Turn-by-turn directions
- Origin and destination selection
- Dynamic route calculation
- Responsive map updates

## Running the Project

1. Clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Select a starting city and a destination city.
5. View the calculated driving route and directions.

> This project uses the Google Maps JavaScript API. A valid API key may be required if the included key is no longer active.
